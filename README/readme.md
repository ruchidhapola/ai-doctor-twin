# AI Digital Doctor Twin

AI-powered healthcare platform that analyzes medical reports and provides personalized health insights.

## Features

* Upload Medical Reports (PDF)
* Extract Health Data
* Risk Prediction
* AI Health Summary
* Interactive Dashboard
* Health Charts
* AI Health Chatbot
* Digital Health Twin Simulation
* Downloadable PDF Health Report

## Tech Stack

### Frontend

* Next.js
* React
* TypeScript
* Tailwind CSS

### Backend

* FastAPI
* Python
* ReportLab
* PDF Processing

## Project Flow

1. Upload Medical Report
2. Extract Health Metrics
3. Predict Health Risk
4. Generate AI Summary
5. View Dashboard
6. Chat with AI Assistant
7. Run Health Simulations
8. Download PDF Report

## Run Frontend

```bash
npm install
npm run dev
```

## Run Backend

```bash
pip install -r requirements.txt
python -m uvicorn main:app --reload
```
